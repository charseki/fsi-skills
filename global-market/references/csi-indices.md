# CSI 中证指数 (H-series) 数据参考

## 数据源状态

| 数据源 | H-series 支持 | 备注 |
|--------|--------------|------|
| 腾讯 qt.gtimg.cn | ❌ | 返回 `v_pv_none_match="1"` |
| 新浪 hq.sinajs.cn | ❌ | 返回空字符串 |
| 东方财富 push2 | ❌ | 腾讯云环境拦截 |
| 中证官网 csindex.com.cn | ⚠️ | Vue SPA, 无法 curl 解析 |
| 天天基金 fundgz | ✅ (通过跟踪基金) | 需先找到对应基金代码 |
| 腾讯 smartbox | ✅ (名称→代码映射) | 搜索中文名获取基金/ETF 代码 |

## 核心方案

H-series CSI 指数无法直接查询，必须通过**跟踪该指数的基金/ETF**来估算涨跌幅：

1. Tencent smartbox 搜索中文名 → 找到基金/ETF 代码
2. 天天基金 API 查基金估算净值变动 → 近似指数今日涨跌幅
3. 腾讯行情查 ETF 实时价 → 近似指数实时行情

## Tencent Smartbox API 详解

**端点**：`https://smartbox.gtimg.cn/s3/?v=2&q={中文名}&t={type}`

**参数**：
- `q`：搜索关键词（中文、拼音、代码均可）
- `t`：过滤类型，`all` 返回全部，`zs` 仅指数，`jj` 仅基金
- `v`：版本号，固定为 `2`

**返回格式**（GBK 编码）：
```
v_hint="市场~代码~名称~拼音缩写~类型^市场~代码~名称~拼音缩写~类型..."
```

**示例解析**：
```
sh~512890~红利低波ETF华泰柏瑞~hldbetfhtbr~ETF^jj~007466~华泰柏瑞中证红利低波ETF联接A~htbrzzhldbdetflja~KJ
```

每条记录用 `^` 分隔，字段用 `~` 分隔：
- 字段0：市场（sh/sz）
- 字段1：证券代码
- 字段2：中文名称
- 字段3：拼音缩写
- 字段4：类型（ZS=指数, ETF=ETF, JJ/KJ=基金）

**curl 命令**：
```bash
curl -s "https://smartbox.gtimg.cn/s3/?v=2&q=红利低波&t=all" | iconv -f GBK -t UTF-8
```

## 天天基金 API 字段

**端点**：`https://fundgz.1234567.com.cn/js/{6位基金代码}.js`

**返回格式**：`jsonpgz({...})`，需提取花括号内 JSON。

**关键字段**：
- `gszzl`：估算涨跌幅（百分比，如 0.66 表示 +0.66%）
- `gsz`：估算净值
- `dwjz`：最新公布净值
- `jzrq`：净值日期
- `gztime`：估算时间

**注意**：`gszzl` 是盘中估算值，指数涨跌幅可通过它近似推算。

## Procedure（查询 CSI 指数）

当用户输入 CSI H-series 代码（如 H30269）：

```bash
# Step 1: 检查 smartbox 是否有已知映射
# 从记忆中的映射表查找该指数代码（见上方映射表）

# Step 2: 通过基金 API 获取估算涨跌幅
curl -s "https://fundgz.1234567.com.cn/js/007466.js"

# Step 3: 通过 ETF 获取实时价（可选）
curl -s "https://qt.gtimg.cn/q=sh512890" | iconv -f GBK -t UTF-8

# Step 4: 汇总结果
echo "H30269 中证红利低波动指数 今日估算涨跌幅: +0.66% (通过007466推算)"
```

memory(action='add', target='memory', content='CSI mapping: H30269(红利低波) tracking funds - ETF:512890, fund:007466')
